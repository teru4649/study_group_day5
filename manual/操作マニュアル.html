感度分析・期待値計算ツール
操作マニュアル

CSVで定義した収支モデルをもとに、樹形図・トルネードチャート・感度分析・モンテカルロシミュレーション・損益分岐点分析を行うための社内向けツールです。 本マニュアルは、アクセス用パスワードを知っている方向けに、ツールで何ができるか・どう操作するかをまとめたものです。

対象: パスワードを知っている関係者 形式: パスワード保護付き Streamlit アプリ 入力: node_id 形式の CSV 1 ファイル

01このツールについて

「感度分析・期待値計算ツール」は、売上・原価・稼働率などの項目を四則演算で組み上げた収支モデルを CSV としてアップロードし、 その収支が各項目の変化にどれだけ敏感か(感度)を複数の角度から確認するための Streamlit アプリです。

できること

  • 項目同士の足し算・引き算・掛け算・割り算の関係を樹形図として可視化し、収支(最終結果)を自動計算する
  • 各項目の最悪値・最良値から、収支への影響度をトルネードチャートで比較する
  • 収支をちょうど0にする値を逆算する「ゴールシーク」を実行する
  • 2項目を同時に動かしたときの収支をヒートマップで確認する(感度分析)
  • 各項目に確率分布を設定し、モンテカルロシミュレーションで収支のばらつきとリスクを試算する
  • 各項目単独の損益分岐点(黒字と赤字の境目)と、そこまでの余裕度を一覧表示する
想定する使い方 事業計画や設備投資などの収支モデルを組んでいる担当者が、前提条件のどこにリスクが集中しているかを説明・議論するための補助ツールです。 表計算ソフトでの感度分析を、ブラウザ上で素早く・繰り返し試せるようにしたものと考えると分かりやすいです。

04CSVファイルの仕様

収支モデルは「ノード(項目)」の一覧として表現します。1行が1項目に対応し、parent_id で親子関係を、 operator で親ノードの計算方法を指定します。

列の仕様(◯必須・△任意)
列名内容必須/任意
node_id項目を一意に識別するID◯必須
parent_id親ノードのID。空欄の行がルート(収支)になる。ルートは1行のみ。◯必須
label画面に表示する項目名◯必須
operator中間ノード(子を持つ行)の演算子。add / subtract / multiply / divide のいずれか。末端ノードは空欄。末端は空欄可
value末端ノードの基準値。中間ノードは計算結果が自動的に入る。末端は◯必須
worst_value末端ノードの最悪値(トルネード・感度分析・モンテカルロの初期範囲に使用)△任意
best_value末端ノードの最良値△任意
unit表示用の単位(円、%、件 など)△任意
order同じ親を持つ子ノードの計算順序。subtract / divide のように順序で結果が変わる演算で重要。△任意
distributionモンテカルロで使う分布。normal / triangular / uniform のいずれか(すべて英小文字)。△任意
param1 param2 param3分布のパラメータ。詳細はモンテカルロの節を参照。△任意

最小構成の例

「収支 = 売上 − 原価」という2項構成のシンプルな例です。

node_id,parent_id,label,operator,value,worst_value,best_value,unit,order
root,,収支,subtract,,,,,
sales,root,売上,,1000,800,1300,円,1
cost,root,原価,,600,500,750,円,2
末端ノードと中間ノードの見分け方 「他の行から parent_id として参照されている行」が中間ノード、「参照されていない行」が末端ノードです。 値を直接編集できる(モデル式ページの「値の編集」など)のは末端ノードのみで、中間ノードの値は常に自動計算されます。

05–09各ページの使い方

左のメニュー(Streamlitのページナビゲーション)から、次の5つのページを切り替えられます。トップページでCSVを未アップロードの場合、各ページには警告が表示され先に進めません。

05

モデル式(樹形図)

収支モデルの構造と計算結果を確認する、最初に見るページ

アップロードしたCSVの構造をツリー図として表示し、収支(ルートノード)の計算結果を確認できます。

  1. 「値の編集」の表で、末端項目(演算子を持たない行)の value を書き換える。編集はその場で樹形図と収支に反映される。
  2. ページ上部の指標で、収支(ルートノードの計算結果)を確認する。
  3. 樹形図はマウスホイールで拡大縮小、ドラッグで移動できる。項目・値・演算子がノードごとに表示される。
  4. 編集を取り消したい場合は「元の値にリセット」を押す(CSVの元の値に戻る)。
必須列が不足している場合 CSVに node_id / parent_id / label / operator / value のいずれかが無いと、 「CSVに必要な列が不足しています」というエラーが表示され、先のページに進めません。
06

トルネードチャート

各項目単独の振れ幅が収支に与える影響を比較する

各末端項目を worst_value と best_value の間で1つずつ動かし、収支への影響幅を横棒グラフで比較します。棒が長い項目ほど、収支への影響が大きい項目です。

  1. 「値の編集」表で、対象項目の worst_value / best_value を調整する。
  2. 「ゴールシーク(収支を0にする)」で、対象項目と「逆算する対象(worst_value または best_value)」を選び、「ゴールシークを実行」を押すと、収支がちょうど0になる値が自動計算され、その項目に反映される。他の項目の値は変わらない。
  3. 下部のグラフで、各項目の影響幅(灰色の点線が現在の収支)を確認する。表には数値の一覧も表示される。
対象になる項目 worst_value と best_value の両方が入力されている末端項目だけがグラフに表示されます。どちらかが空欄の項目は対象外です。
07

感度分析

2項目を同時に動かしたときの収支をヒートマップで見る

横軸・縦軸に選んだ2つの項目を格子状に動かし、それぞれの組み合わせでの収支をヒートマップで表示します。赤いほど赤字、青いほど黒字です。

  1. 「横軸の項目」「縦軸の項目」をそれぞれ選ぶ(末端項目が2つ以上必要)。
  2. 「動かす範囲の設定」で、各項目のスライダー範囲を調整する。初期値は worst_value〜best_value(未設定の場合は基準値の±50%)。
  3. 「分割数(格子の細かさ)」で、何段階で計算するかを設定する(多いほど滑らかだが計算に時間がかかる)。
  4. ヒートマップ上のセルの数値が、その組み合わせにおける収支の計算結果。
08

モンテカルロ

確率分布に基づき収支のばらつきとリスクを試算する

各項目に確率分布を設定したうえで大量の試行を行い、収支がどのように分布するか、赤字になる確率がどれくらいかを確認します。

選べる分布とパラメータの意味
分布param1param2param3
normal(正規分布)平均標準偏差使用しない
triangular(三角分布)最小値最頻値最大値
uniform(一様分布)最小値最大値使用しない
  1. 「分布パラメータの設定」で、各項目のプルダウンから分布を選ぶ。worst_value / best_value の両方がある項目のみ、分布を選択できる。
  2. 分布を選ぶと param1〜3 に目安の初期値が自動的に入るので、必要に応じて調整する。
  3. 「この内容で分布設定を保存」を押して確定する。
  4. 「試行回数」を設定し、「シミュレーションを実行」を押す。
  5. 結果として、収支のヒストグラム・累積確率曲線・赤字になる確率・主要パーセンタイル(5%〜95%)が表示される。
分布名は英小文字で正確に CSVの distribution 列を直接編集する場合は、normal / triangular / uniform と完全に一致する半角小文字で入力してください。 Normal や前後の空白付きなど、少しでも表記が異なると分布未設定として扱われ、値を変えても結果が変わらなくなります。 画面上のプルダウンから選ぶ場合はこの心配はありません。
09

損益分岐点分析

各項目単独の黒字・赤字の境目と、その余裕度を一覧で見る

他の項目をすべて固定したまま、対象項目だけを動かして収支がちょうど0になる値(損益分岐点)を、末端項目ごとに一覧表示します。

  • 現在値・損益分岐点・差分:現在の値と分岐点、その差。
  • 安全余裕率(%):現在値から分岐点までの変化率。0に近いほど、少しの変化で赤字転落するリスクが高い項目。
  • 下部のグラフでは、安全余裕率が±10%以内の項目を赤色で強調表示する。

10注意点・トラブルシューティング

症状主な原因と対処
「ルートノード(parent_idが空の行)が見つかりません」 parent_id が空欄の行が無いか、複数ある。収支を表す行を1行だけ空欄にする。
「node_id '…' がCSV内に見つかりません」 parent_id に、実在しない node_id を指定している。誤字や行の削除漏れを確認する。
引き算・割り算の結果が意図と逆になる 同じ親を持つ子ノードの計算順序は order 列で決まる。order が無い場合はCSVの行順に依存するため、明示的に指定するのが安全。
モンテカルロで値を変えても結果が変わらない distribution の表記ゆれ(大文字・空白など)が主な原因。上の「分布名は英小文字で正確に」を参照。
アップロードし直しても前のデータのまま 同名・同サイズのファイルは再読み込みされない仕様。トップページの「データを完全リセット」を押してから再アップロードする。
感度分析ページで項目が選べない 末端項目(演算子を持たない行)が2つ以上必要。中間ノードしか無い、または末端項目が1つしか無いCSVでは選択肢が出ない。

11アプリ内へのマニュアル組み込み

本ファイル(HTML)は単独でも開けますが、Streamlitアプリの新しいページとして組み込み、アプリ内から直接マニュアルを確認できるようにすることもできます。

方法A: マニュアル専用ページを追加する

このHTMLファイルをリポジトリに追加し(例: manual/操作マニュアル.html)、pages/ 配下に読み込み用のページを1つ作成します。 streamlit_app.py の st.navigation([...]) にもページを追加すると、他のページと同じメニューに表示されます。 

# pages/0_使い方.py
import streamlit as st
import streamlit.components.v1 as components
 
st.title("使い方(操作マニュアル)")
 
with open("manual/操作マニュアル.html", encoding="utf-8") as f:
    html = f.read()
 
components.html(html, height=900, scrolling=True)
ページの並び順 streamlit_app.py 内の st.Page(...) の並びがメニューの表示順です。マニュアルページを一番上に置きたい場合は、 st.navigation([...]) のリストの先頭に追加してください。

方法B: パスワード入力前の案内として使う

パスワードを知らない人にもツールの概要だけ伝えたい場合は、本HTMLの「01 このツールについて」の内容だけを抜き出し、 check_password() が False を返している間(ログイン前)の画面に st.markdown 等で表示する方法もあります。
